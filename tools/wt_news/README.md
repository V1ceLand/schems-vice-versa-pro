# Новостной бот War Thunder для Telegram

Инструменты для запланированной задачи: собрать свежие новости War Thunder,
взять картинку с источника, написать пост и опубликовать его в канал.

Текст поста пишет Claude в момент запуска задачи — скрипты отвечают только за
сбор данных, отправку и учёт уже опубликованного.

## Настройка (один раз)

1. Создайте бота у [@BotFather](https://t.me/BotFather), получите токен.
2. Добавьте бота администратором канала с правом «Публикация сообщений».
3. Задайте переменные окружения (в настройках окружения Claude Code на вебе —
   Environments → Environment variables, либо в локальном `.env`):

   ```
   TG_BOT_TOKEN=123456:AA...
   TG_NEWS_CHANNEL=@my_warthunder_channel
   ```

4. Проверьте связку:

   ```bash
   php tools/wt_news/check.php
   ```

## Скрипты

### `fetch_news.php` — кандидаты для поста

```bash
php tools/wt_news/fetch_news.php --limit=5                    # новости warthunder.com/ru/news
php tools/wt_news/fetch_news.php --source=changelog --limit=3 # патчноуты
php tools/wt_news/fetch_news.php --lang=en --limit=5          # англоязычная лента
php tools/wt_news/fetch_news.php --all                        # без фильтра по posted.json
```

Печатает JSON: `url`, `title`, `summary`, `date`, `image` (обложка `og:image`),
`images` (до 10 крупных картинок статьи), `body` (текст статьи, по умолчанию
до 2500 символов). Уже опубликованное из `posted.json` отсеивается.

### `publish.php` — публикация

```bash
php tools/wt_news/publish.php \
  --url=https://warthunder.com/ru/news/17945-... \
  --image=https://staticfiles.warthunder.com/... \
  --text-file=/tmp/post.txt \
  --title="Заголовок новости"

# посмотреть, что уйдёт в канал, ничего не отправляя:
php tools/wt_news/publish.php ... --dry-run
```

- подпись длиннее 1024 символов автоматически режется по абзацу, хвост уходит
  ответом на пост;
- картинка скачивается локально и отправляется файлом (у staticfiles бывает
  403 на прямую загрузку Telegram'ом);
- если фото не приняли — пост уходит текстом, чтобы не потеряться;
- после успеха новость записывается в `posted.json`.

Коды выхода: `0` — успех, `1` — ошибка отправки, `2` — ошибка параметров или
настройки, `3` — новость уже публиковалась.

### `mark_posted.php` — пропустить новость

```bash
php tools/wt_news/mark_posted.php --url=... --reason=не-подходит-каналу
```

### `posted.json` — память бота

Контейнер запланированной задачи каждый раз создаётся заново, поэтому файл
состояния лежит в репозитории и **должен коммититься и пушиться после каждой
публикации** — иначе на следующем запуске новость уйдёт в канал повторно.

## Формат поста

- Язык: русский. Тон: сухой новостной, без эмодзи и оценок.
- Разметка Telegram HTML: `<b>`, `<i>`, `<a href="">`, `<code>`. Не Markdown.
- Структура: жирный заголовок → 2–4 коротких абзаца фактов (что, когда, кому
  доступно, сроки, цена) → строка со ссылкой на источник.
- Только факты из источника. Ничего не додумывать: нет числа в источнике —
  нет числа в посте.
- Хештеги в конце: `#WarThunder` и один тематический
  (`#обновление`, `#событие`, `#девблог`, `#киберспорт`).

## Ручной прогон

```bash
php tools/wt_news/fetch_news.php --limit=3 > /tmp/wt.json
# выбрать новость, написать текст в /tmp/post.txt
php tools/wt_news/publish.php --url=... --image=... --text-file=/tmp/post.txt --dry-run
```
