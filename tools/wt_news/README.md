# Новостной бот War Thunder для Discord

Инструменты для запланированной задачи: собрать свежие новости War Thunder,
взять картинку с источника, написать пост и опубликовать его в канал Discord.

Текст поста пишет Claude в момент запуска задачи — скрипты отвечают только за
сбор данных, отправку и учёт уже опубликованного.

## Настройка (один раз)

1. Создайте приложение и бота в [Developer Portal](https://discord.com/developers/applications),
   получите токен бота.
2. Пригласите бота на сервер и в настройках нужного канала дайте его роли
   права: «Просмотр канала», «Отправлять сообщения», **«Прикреплять файлы»**
   и «Встраивать ссылки». Без «Прикреплять файлы» текст уйдёт, а картинки
   Discord отклонит с ошибкой 50013.
3. Возьмите id канала: включите режим разработчика в настройках Discord,
   правый клик по каналу, «Копировать ID».
4. Задайте переменные окружения (в настройках окружения Claude Code на вебе,
   в локальном `.env` или прямо в промпте запланированной задачи):

   ```
   DISCORD_BOT_TOKEN=MTU0...
   DISCORD_CHANNEL_ID=1542598100940619897
   ```

   В репозиторий токен не коммитим: `.env` в `.gitignore`, и это не случайно.

4. Проверьте связку:

   ```bash
   php tools/wt_news/check.php
   ```

## Скрипты

### `fetch_news.php` — кандидаты для поста

```bash
php tools/wt_news/fetch_news.php --limit=5                    # новости warthunder.com/ru/news
php tools/wt_news/fetch_news.php --source=changelog --limit=3 # патчноуты
php tools/wt_news/fetch_news.php --lang=en --limit=5          # англоязычная лента
php tools/wt_news/fetch_news.php --all                        # без фильтра по posted.json
```

Печатает JSON: `url`, `title`, `summary`, `date`, `image` (обложка `og:image`),
`images` (до 10 крупных картинок статьи), `body` (текст статьи, по умолчанию
до 2500 символов). Уже опубликованное из `posted.json` отсеивается.

### `publish.php` — публикация

```bash
# одно фото
php tools/wt_news/publish.php \
  --url=https://warthunder.com/ru/news/17945-... \
  --image=https://staticfiles.warthunder.com/... \
  --text-file=/tmp/post.txt \
  --title="Заголовок новости"

# несколько фото одним сообщением (до 10 вложений)
php tools/wt_news/publish.php --url=... --images=url1,url2,url3 --text-file=/tmp/post.txt

# посмотреть, что уйдёт в канал, ничего не отправляя:
php tools/wt_news/publish.php ... --dry-run
```

- все картинки уходят одним сообщением вложениями (до 10 штук);
- текст длиннее 2000 символов режется по абзацу, хвост уходит вторым
  сообщением;
- картинки скачиваются локально и загружаются файлами: Discord принимает
  вложения только загрузкой, а staticfiles отдаёт 403 чужим загрузчикам;
- если вложения не приняли (например, нет права «Прикреплять файлы»),
  пост уходит текстом: новость не теряется, но в `posted.json` пишется
  пустой список картинок;
- после успеха новость записывается в `posted.json`.

Коды выхода: `0` — успех, `1` — ошибка отправки, `2` — ошибка параметров или
настройки, `3` — новость уже публиковалась.

### `fetch_freebies.php` — халява

```bash
php tools/wt_news/fetch_freebies.php                  # всё, включая скидки
php tools/wt_news/fetch_freebies.php --min-score=4    # только по-настоящему бесплатное
php tools/wt_news/fetch_freebies.php --no-forum       # без форума
```

Ищет промокоды, Twitch Drops, раздачи, подарки, купоны и скидки в
официальных новостях и на forum.warthunder.ru (Discourse: свежие темы плюс
поиск за последний месяц). Каждой находке считается `score`: промокод 5,
бесплатное 4, раздача 4, дропсы 4, купон 2, награда за просмотр 2, скидка 1.

Форумные находки помечены `"unverified": true`. Это слова игроков, а не
источник: половина попаданий будет мимо (тема «вывести бесплатные ЗРК из
игры» тоже содержит слово «бесплатно»). Прежде чем писать пост, условия и
сам код нужно подтвердить на warthunder.com, в официальных соцсетях или на
странице акции.

### `mark_posted.php` — пропустить новость

```bash
php tools/wt_news/mark_posted.php --url=... --reason=не-подходит-каналу
```

### `posted.json` — память бота

Контейнер запланированной задачи каждый раз создаётся заново, поэтому файл
состояния лежит в репозитории и **должен коммититься и пушиться после каждой
публикации** — иначе на следующем запуске новость уйдёт в канал повторно.

## Формат поста

Пишем так, как пишет живой человек, который играет в War Thunder и ведёт канал.
Не пресс-релиз и не пересказ робота.

Что делать:

- Русский язык, спокойный разговорный тон. Можно короткое личное замечание
  по делу («механика давно просилась в танки»), но без восторгов и рекламы.
- Начинать сразу с сути. Никаких «Разбираемся», «Что нужно знать»,
  «Давайте посмотрим».
- Живой ритм: рядом короткие и длинные предложения, а не ровная кашица.
- Конкретика вместо общих слов: сроки, ранги, цены, радиусы, номера версий.
  Нет числа в источнике — нет числа в посте.
- Заголовок обычным предложением, а не Заголовок С Больших Букв.

Чего избегать (по скилу humanizer):

- Тире `—` и `–`: заменять точкой, запятой, двоеточием или скобками.
- Штампов вроде «знаменует важный этап», «подчёркивает значимость»,
  «открывает новые возможности», «остаётся только ждать».
- Деепричастных хвостов «подчеркивая…», «обеспечивая…», «делая игру…».
- Перечислений ровно по три пункта ради красоты.
- Конструкций «не просто X, а Y».
- Эмодзи в тексте и жирного выделения без причины.
- Хештегов. В Discord они бесполезны.
- Бодрой концовки в пустоту. Заканчивать последним фактом или ссылкой.
- Ссылок на несуществующие источники, догадок и додумываний.

Разметка Discord Markdown: `**жирный**`, `*курсив*`, `` `код` ``. HTML не
работает. Ссылку на источник оборачиваем в угловые скобки (`<https://...>`),
иначе Discord прицепит карточку предпросмотра поверх наших картинок.

Структура свободная, но обычно: заголовок жирным, 2–4 абзаца по делу и
строка с источником в конце. Хештеги не ставим: в Discord они ничего не
дают и только засоряют пост.

Длина: до 2000 символов на сообщение.

## Халява — приоритет

Раздачи, промокоды, дропсы и бесплатные наборы канал интересуют больше
всего, поэтому такие материалы идут вперёд очереди, а не в порядке даты.
У них короткий срок жизни: пост про дропсы нужен до стрима, а не через
неделю после.

Что обязательно в таком посте: что дают, где забирать, до какого числа и
что нужно сделать, чтобы получить. Промокод пишем целиком в обратных кавычках, чтобы его было удобно
скопировать, и рядом ставим ссылку на место, где он опубликован.

Чего не делать:

- не брать коды с сайтов-агрегаторов промокодов (fivepost, cashbe, pikabu
  и подобные). Там почти всегда просроченный мусор или реферальные ссылки
  под видом кодов;
- не публиковать код, который не удалось найти в официальном источнике или
  хотя бы в живой форумной теме с подтверждениями;
- не додумывать сроки и условия. Не написано до какого числа — так и
  пишем, что срок не указан.

## Сколько фото

Одно фото — если у новости одна осмысленная картинка. 2–4 фото —
если в статье есть разные кадры техники, скриншоты экипировки, карты события.
Мусор не добавлять: три ракурса одной и той же машины лучше, чем десять
случайных картинок со страницы.

## Ручной прогон

```bash
php tools/wt_news/fetch_news.php --limit=3 > /tmp/wt.json
# выбрать новость, написать текст в /tmp/post.txt
php tools/wt_news/publish.php --url=... --image=... --text-file=/tmp/post.txt --dry-run
```
