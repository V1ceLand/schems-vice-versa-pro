# «Пары» — сайт-витрина

Страница-продажник Android-приложения «Пары»: расписание с чётными и нечётными
неделями, замены, домашние задания, чат и роли группы. Главное на странице —
не скриншоты, а живой экран приложения: он работает прямо в браузере.

## Структура

| Файл | Что делает |
| --- | --- |
| `index.html` | Разметка страницы: демонстрация, возможности, «один день», аудитории, группа, цены, как начать, FAQ |
| `assets/tokens.css` | Фирменная палитра, светлая и тёмная |
| `assets/site.css` | Оформление страницы вокруг телефона |
| `assets/phone.css` | Экран приложения: корпус, шапка, полоса недели, карточки, нижняя навигация |
| `assets/engine.js` | Расчёт учебного дня: чётность недели, занятия на дату, фазы дня |
| `assets/data.js` | Данные для показа: расписание, задания, чат, участники, тарифы |
| `assets/icons.js` | Инлайновые SVG-иконки |
| `assets/app.js` | Отрисовка экранов, «машина времени», сценарии, блоки страницы |

## Что показывает демонстрация

Экран телефона переключается по вкладкам «Сегодня», «Неделя», «Задания», «Ещё»
и открывает вложенные экраны: профиль, группа, форум, чат, настройки,
обновление. Рядом — панель управления:

- ползунок времени суток и кнопка «Проиграть день»: карточка дня, обратный
  отсчёт и подсветка занятий меняются на каждом шаге;
- перемотка к моменту дня (утро до пар, идёт пара, пятиминутка, перерыв,
  после пар); кнопка гаснет, если такого момента в выбранном дне нет;
- быстрый переход к любому разделу приложения.

Все данные на экране вымышлены, сеть не используется.

## Правки текста и цен

- тексты секций — в `index.html`;
- расписание, задания, сообщения, участники, тарифы и права ролей — в
  `assets/data.js` (страница перерисуется сама, сборка не нужна);
- цвета — в `assets/tokens.css`.

## Запуск

Статика без сборки, но модули грузятся только по HTTP — открывать `file://`
бесполезно:

```bash
cd pairs-demo
python3 -m http.server 8080
# http://localhost:8080
```

## Публикация на своём сервере

В `deploy/` лежит всё, что нужно для сервера с nginx (проверено на Ubuntu 24.04):

- `nginx-pairs-demo.conf` — server-блок: отдача статики, gzip, запрет на
  выдачу README и служебных файлов;
- `install.sh` — раскладывает файлы, включает конфигурацию и перезагружает nginx.

Скопируйте каталог `pairs-demo` на сервер и выполните на нём:

```bash
cd pairs-demo
sudo ./deploy/install.sh
```

Скрипт кладёт `index.html` и `assets/` в `/var/www/pairs-demo`, ставит
конфигурацию в `sites-available`, выключает стандартную страницу nginx
и перезагружает сервер. На сервер едут только файлы сайта — README,
скрипты и конфигурация остаются в репозитории.

Опции:

```bash
sudo ./deploy/install.sh --root /var/www/pairs      # другой каталог
sudo ./deploy/install.sh --server-name pairs.ru     # если есть домен
sudo ./deploy/install.sh --keep-default             # не трогать стандартный сайт
```

Если проверка конфигурации не пройдёт, скрипт вернёт всё как было и
не станет перезагружать nginx — работающий сайт не сломается.

HTTPS ставится отдельно и одной командой: `certbot --nginx -d ваш-домен`.
Для голого IP сертификат не выпускается — нужен домен.

Кнопки «Установить» ведут на секцию с инструкцией: подставьте туда прямую
ссылку на файл установки, когда решите, откуда его раздавать.

## Внешние зависимости

Одна: шрифт Roboto. Без сети страница берёт системный гротеск — раскладка
не ломается. Ни фреймворков, ни сборки, ни аналитики, ни счётчиков.
