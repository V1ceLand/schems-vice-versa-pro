# «Пары» — демонстрационный сайт

Витрина Android-приложения «Пары» (`kozyr.smisl.app`): расписание с чётностью
недель, задания, чат группы, роли и уведомления. Главное на странице — не
скриншоты, а работающий экран приложения: расписание раскладывается и фаза
учебного дня считается прямо в браузере.

## Что внутри

| Файл | Что делает |
| --- | --- |
| `index.html` | Вся разметка страницы: демонстрация, возможности, разбор расчёта, роли, тарифы, установка, FAQ |
| `assets/tokens.css` | Палитра Material 3, перенесённая из `ui/theme/Color.kt` приложения (светлая и тёмная) |
| `assets/site.css` | Оформление страницы вокруг телефона |
| `assets/phone.css` | Экран приложения: корпус, шапка, полоса недели, карточки, нижняя навигация |
| `assets/engine.js` | Порт `ScheduleEngine.kt`: чётность недели, раскладка занятий на дату, фазы дня |
| `assets/data.js` | Демонстрационные данные: звонки и чётная неделя из `SeedData.kt`, остальное дописано |
| `assets/icons.js` | Инлайновые SVG-иконки, красятся через `currentColor` |
| `assets/app.js` | Отрисовка экранов, «машина времени», сценарии фаз, статические блоки страницы |

## Что показывает демонстрация

Экран телефона переключается по вкладкам «Сегодня», «Неделя», «Задания», «Ещё»
и открывает вложенные экраны: профиль, группа, форум, чат, настройки,
обновление. Рядом — панель управления:

- **машина времени** — ползунок времени суток и кнопка «Проиграть день»;
  карточка дня, прогресс и подсветка занятий пересчитываются на каждом шаге;
- **фазы дня** — прыжок к моменту, где день находится в нужной фазе
  (до первой пары, идёт пара, пятиминутка, перерыв, день закончился);
  кнопка гаснет, если такой фазы в выбранном дне нет;
- **экраны** — быстрый переход к любому экрану приложения.

Расчёт повторяет приложение: чётность считается от опорной даты (обе даты
приводятся к понедельнику), замена на день вытесняет постоянное расписание и
помечает «только сегодня» ровно те пары, что отличаются от обычной недели,
режим «отпускают на 5 минут раньше» сдвигает конец пары, а «перерыв в середине»
вырезает пять минут по центру.

Данные вымышленные, сети демонстрация не использует: сервер, аккаунты и оплата
за пределами этой страницы.

## Запуск

Статика без сборки, но модули ES грузятся только по HTTP — открывать
`file://` бесполезно:

```bash
cd pairs-demo
python3 -m http.server 8080
# http://localhost:8080
```

## Публикация

Подойдёт любой статический хостинг: скопировать каталог целиком в корень сайта.
Для nginx достаточно раздачи файлов, ничего проксировать не нужно:

```nginx
server {
  listen 80;
  root /var/www/pairs-demo;
  index index.html;
  location / { try_files $uri $uri/ =404; }
}
```

Ссылки «Скачать APK» ведут на якорь с инструкцией. Если сайт публикуется рядом
с бэкендом «Пар», кнопку в секции «Установка» можно направить прямо на
`/download/android` — эндпоинт отдаёт APK с именем вида `Pairs-4.8.apk`.

## Внешние зависимости

Одна: шрифт Roboto с Google Fonts. Без сети страница берёт системный
гротеск — раскладка не ломается. Ни фреймворков, ни сборки, ни аналитики.
